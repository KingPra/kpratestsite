# kingpra.com

Source for King Pra's portfolio: a dark, minimal single-page site with a morphing-particle hero, a lineage river, and a pop-up terminal.

- `content.js`: all of the site's text, projects and links. Edit this to update the site.
- `site.js`: the page (particle hero, project cards, lineage river and demo, contact form).
- `terminal.js`: the pop-up terminal (press the backtick key or click Terminal).
- `style.css`: styles.
- `contact.php`: emails contact form messages to info@kingpra.com (needs PHP hosting).
