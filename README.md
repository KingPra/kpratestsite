# kingpra.com

Source for King Pra's portfolio: a modern single-page site with a built-in pop-up terminal.

- `content.js`: all of the site's text, projects and links. Edit this to update the site.
- `site.js`: the page (hero lineage graph, project cards, lineage demo, contact form, theme).
- `terminal.js`: the pop-up terminal (press the backtick key or click Terminal).
- `style.css`: styles, light and dark themes.
- `contact.php`: emails contact form messages to info@kingpra.com (needs PHP hosting).
